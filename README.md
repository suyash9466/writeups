## Vulnerability Writeups

### OTP Bypass (Business Logic Flaw)

A business logic vulnerability where improper server-side validation allowed bypassing OTP verification in a test ride booking flow.

[View Writeup](OTP%20Bypass%20(Business%20Logic%20Flaw).md)

### CSRF (Cross-Site Request Forgery) – Password Reset Account Takeover

A CSRF vulnerability in the password reset functionality that could allow attackers to change a victim’s password without consent.

[View Writeup](./CSRF-Password-Reset-Account-Takeover.md)

### Session Management Flaw – 2FA Bypass on Pre-Existing Sessions (Snapchat)

A session management vulnerability where enabling TOTP-based 2FA did not invalidate existing authenticated sessions, allowing password and email changes without re-authentication.

[View Writeup](https://github.com/suyash9466/writeups/blob/main/Session-Management-Flaw-2FA-Bypass-Snapchat.md)
